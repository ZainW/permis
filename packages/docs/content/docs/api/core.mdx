## PermisEngine

```ts
import { PermisEngine } from "@permis/core";

const engine = new PermisEngine({ roles: [reader, editor] });

engine.can(editor, "write", { type: "documents" });
engine.authorize(admin, "manage", { type: "users" });
```

## Core Types

| Type           | Description                                         |
| -------------- | --------------------------------------------------- |
| `Subject`      | The entity requesting access (user, role, etc.)     |
| `Resource`     | The entity being accessed (document, user, etc.)    |
| `SubjectId`    | Unique identifier for a subject                     |
| `Action`       | The action being performed (`create`, `read`, etc.) |
| `ResourceType` | String identifier for a resource type               |
